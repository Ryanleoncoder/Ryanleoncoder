## Projetos em Destaque

### Experience Connect

Plataforma focada em uma nova abordagem de aprendizado baseada em experiências práticas, desafios e desenvolvimento contínuo. O projeto busca transformar o processo de capacitação em algo mais próximo da realidade do mercado, utilizando tecnologia para conectar conhecimento, prática e evolução profissional.

**Áreas envolvidas:** Arquitetura de Sistemas • IA • Desenvolvimento Web • Experiência do Usuário

---

### CR Store

Plataforma interna de recompensas com sistema de moedas virtuais, catálogo de produtos, carteira digital, controle de permissões e painel administrativo.

O projeto envolve desde a modelagem do banco de dados até o desenvolvimento da interface, autenticação, regras de negócio e infraestrutura em nuvem.

**Stack:** JavaScript • Supabase • PostgreSQL • Vercel
